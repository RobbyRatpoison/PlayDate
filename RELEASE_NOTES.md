# Release Notes

## v1.5.18 — Pending

### Improvements

- BLAEO sync now runs in the background. Start a sync from Community Tools and continue using the app while it scrapes. A notification dot and menu item appear in the hamburger menu when results are ready; clicking it opens the BLAEO review panel to confirm or discard changes.
- Applying a built-in filter preset (Installed, Never Played, Beaten, etc.) now stores it as proper filter tree conditions instead of raw SQL. Reopening the filter modal after applying a preset shows editable rows in the simple editor rather than the advanced SQL box.
- Clearing filters (✕ CLEAR in the library bar, or CLEAR ALL in the filter modal) no longer resets platform source toggles.
