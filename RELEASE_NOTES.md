# Release Notes

## v1.5.15

### Bug Fixes

- PAGYWOSG qualifications panel now always shows the current month's event label instead of the previous month's when the new event starts at the end of the prior month.
- PAGYWOSG quals panel: title-letter categories (e.g. "Games starting with S" or "Games starting with T, H, U, M, B, or S") are now auto-detected instead of requiring mod verification or not appearing at all.
- PAGYWOSG quals panel: weekday release categories (e.g. "Released on a Sunday") are now auto-detected.
- Filter modal: the Platform condition dropdown now only lists platforms present in your library.
- PAGYWOSG quals panel: pool membership (win vs backlog) now correctly reflects your SteamGifts wins group even when no PAGYWOSG filter is currently active. Previously, games would show all categories as "(backlog)" and omit wins-only categories entirely.
