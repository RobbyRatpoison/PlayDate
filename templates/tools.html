Tools

Utilities for managing and maintaining your PlayDate library.

Edit Home Layout

Rearrange, rename, add, or remove shelves on the home page. Configure what each shelf displays using presets or custom SQL, set row heights, column widths, game limits, and dedup priority.

Tip: press E anywhere on the home page to open the editor directly.

Open Home Layout Editor

Background Image

Replace the app background with a custom image, or reset to the default.

Backup & Restore

Save a snapshot of your library, settings, and cover art. Restore from any previous backup to roll back changes or migrate to a new machine.

BLAEO Sync

Fetch completion statuses (Beaten, Completed, Won't Play, etc.) and list tags from your BLAEO backlog profile. Requires Chrome to be installed.

PAGYWOSG Filter Builder

Build this month's eligible pool from the monthly post criteria and save it as a library filter.

Blacklist Manager

Blacklisted games are permanently skipped by "Populate PlayDate" and will never be re-added to your library. To blacklist a game, delete it via the edit modal and choose to blacklist it when prompted.

Import Data from Another Database

Copy column data from another database into your current library. Games are matched by AppID. Works with PlayDate backups, older versions, or any compatible database.

Export Library to CSV

Export your game library as a CSV file for use in spreadsheets. Includes name, completion status, tags, groups, playtime, review data, achievements, and more.

Theme Editor

Customize the color scheme of the entire app. Changes are previewed live and applied instantly across all pages when saved.

Background Image

Replace the app background with a custom image. JPG, PNG, and WebP are supported.

Import Data from Another Database

Copy column data from another database into your current library. Games are matched by AppID — only games that exist in both databases will be updated.

1 · Upload File 2 · Map Columns 3 · Done

Select the .db file you want to import data from. Your current library will not be affected until you confirm the import in step 2.

How this works: Choose which table and columns to read from the uploaded file, then map each source column to the matching column in your library.
Most PlayDate databases only have one table: games.
This column is used to match rows — it won't be imported as data.
